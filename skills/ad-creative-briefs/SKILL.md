# Ad Creative Briefs

Write briefs that test a hypothesis, not just generate assets.

## Core insight

Every ad should answer one question: which audience, pain, promise, or proof moves behavior? If the test hypothesis is unclear, performance data will be useless.

## Operating loop

1. Define audience segment, channel, offer, funnel stage, budget sensitivity, and conversion event.
2. Choose one hypothesis per concept: pain, outcome, proof, mechanism, objection, urgency, comparison, or identity.
3. Write the brief: hook, visual concept, copy, CTA, landing page match, proof needed, and compliance notes.
4. Create variants that isolate one variable at a time.
5. Map each concept to expected signal: CTR, CVR, saves, comments, booked calls, CAC, or qualified leads.
6. Include rejection criteria so losing ads teach something.
7. Produce handoff notes for designer, editor, or media buyer.

## Creative angles

- Problem agitation with real user language.
- Before/after transformation.
- Demonstration of the mechanism.
- Social proof from a specific customer type.
- Comparison against the old way.
- Objection reversal.

## Quality bar

- Each ad tests one strategic idea.
- Creative direction is visual, not just copy.
- Claims are supportable and compliant.

## Anti-patterns

- Generating many headlines with no test design.
- Mixing several hypotheses in one ad.
- Sending traffic to a page that does not match the promise.
