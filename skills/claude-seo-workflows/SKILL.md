# Claude SEO Workflows

## Overview

This skill enables Claude to assist with comprehensive SEO workflows for websites, blogs, landing pages, and developer-focused content.

The workflow focuses on:
- keyword research
- search intent analysis
- technical SEO
- content structure optimization
- metadata generation
- internal linking strategy
- search-focused writing
- scalable content workflows

The goal is to create content and site structures that:
- rank effectively
- match user intent
- remain readable and useful
- avoid low-quality AI-generated SEO patterns

This workflow prioritizes high-quality, human-readable content over keyword stuffing or outdated SEO tactics.

# Core SEO Principles

## 1. Prioritize Search Intent

Good SEO begins with understanding:
- why users search
- what users expect
- what problems users want solved

Claude should optimize for:
- usefulness
- relevance
- clarity
- intent satisfaction

Avoid:
- keyword stuffing
- shallow content
- generic filler text

Content that satisfies intent performs better long-term.

---

## 2. Write for Humans First

SEO content should remain:
- readable
- useful
- well-structured
- engaging

Claude should avoid:
- robotic phrasing
- repetitive keyword insertion
- unnatural headings
- over-optimized copy

Good SEO content should feel:
- natural
- authoritative
- trustworthy
- helpful

---

## 3. Build Strong Content Structure

Good content structure improves:
- readability
- crawlability
- ranking potential
- user engagement

Recommended structure:
- clear headings
- logical sections
- concise paragraphs
- strong introductions
- scannable formatting

Claude should:
- organize information clearly
- maintain logical flow
- improve readability continuously

---

## 4. Optimize Metadata Properly

Metadata strongly affects:
- click-through rates
- search visibility
- page relevance

Optimize:
- title tags
- meta descriptions
- heading hierarchy
- image alt text
- structured data opportunities

Avoid:
- duplicate metadata
- vague titles
- keyword stuffing

---

## 5. Improve Technical SEO

Technical SEO improves:
- crawlability
- indexing
- performance
- user experience

Claude should help identify:
- slow-loading pages
- broken links
- poor heading structure
- duplicate content
- missing metadata
- weak internal linking

Technical quality affects long-term ranking stability.

---

## 6. Build Topical Authority

Strong SEO systems focus on:
- topic depth
- content relationships
- internal linking
- consistent expertise

Claude should help create:
- content clusters
- supporting articles
- semantic keyword coverage
- connected content ecosystems

Authority compounds over time.

# Workflow

## 1. Analyze Search Intent

Start by identifying:
- target audience
- search motivation
- competitor positioning
- expected content depth

Determine whether intent is:
- informational
- transactional
- navigational
- commercial investigation

Content structure should adapt to intent.

---

## 2. Research Keywords

Identify:
- primary keywords
- secondary keywords
- semantic variations
- long-tail opportunities

Prioritize:
- relevance
- realistic ranking opportunities
- intent alignment

Avoid:
- chasing irrelevant high-volume keywords
- over-optimizing low-quality traffic

---

## 3. Structure the Content

Create:
- heading hierarchy
- section flow
- internal linking opportunities
- supporting subsections

Good structure improves:
- readability
- ranking potential
- engagement
- crawlability

---

## 4. Optimize Content Quality

Claude should:
- improve clarity
- remove fluff
- strengthen explanations
- add useful examples
- improve readability

Focus on:
- expertise
- usefulness
- specificity
- depth

Avoid:
- repetitive phrasing
- generic filler
- unnecessary keyword repetition

---

## 5. Improve Technical SEO

Validate:
- metadata quality
- heading structure
- URL structure
- internal linking
- image optimization
- mobile readability

Ensure:
- pages remain crawlable
- structure stays logical
- content loads efficiently

---

## 6. Build Internal Linking Strategy

Identify:
- related pages
- supporting content
- topical relationships

Good internal linking improves:
- crawl efficiency
- authority flow
- content discoverability

Avoid:
- isolated pages
- excessive linking
- irrelevant anchor text

---

## 7. Final Validation

Before publishing validate:
- readability
- keyword alignment
- metadata quality
- search intent satisfaction
- technical SEO structure

Ensure:
- the content feels human-written
- structure remains clean
- SEO supports usability rather than hurting it
