# Customer Journey Mapping

Map the customer's lived path, not the company's org chart.

## Core insight

Journeys break at handoffs: ad to landing page, signup to onboarding, trial to activation, support to product, sales to success. The map is useful only if it exposes those handoff failures.

## Operating loop

1. Choose one persona, one scenario, and one desired outcome.
2. Map stages from the customer's perspective: trigger, search, evaluate, start, succeed, expand, recover.
3. For each stage, capture action, question, emotion, touchpoint, owner, metric, and failure mode.
4. Identify moments of truth where confidence increases or collapses.
5. Connect friction to evidence: analytics, tickets, interviews, sales notes, or support logs.
6. Prioritize opportunities by impact, effort, confidence, and owner.
7. Turn the map into an action plan with metrics.

## Friction taxonomy

- Comprehension: user does not understand value or next step.
- Confidence: user does not trust the claim or process.
- Capability: product cannot do what the user needs.
- Coordination: handoff between teams or tools fails.
- Recovery: user hits an error and cannot self-correct.

## Output format

```markdown
| Stage | User question | Touchpoint | Emotion | Friction | Evidence | Opportunity | Metric |
|---|---|---|---|---|---|---|---|
```

## Quality bar

- The map produces prioritized decisions, not just documentation.
- Each high-priority friction point has an owner and metric.
- The journey includes recovery and support, not only acquisition.

## Anti-patterns

- Mapping internal funnel labels as if users think that way.
- Creating a beautiful diagram with no next action.
- Assuming one universal journey for every segment.
