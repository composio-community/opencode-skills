# PowerPoint Generation

## Overview

This skill enables Claude to generate complete PowerPoint presentation workflows from rough notes, ideas, documents, or structured content.

The workflow focuses on:
- slide structure
- presentation storytelling
- visual hierarchy
- concise messaging
- professional formatting
- presentation pacing
- audience-focused communication

The goal is to transform unstructured information into polished, presentation-ready slide decks that are:
- visually organized
- easy to present
- audience-aware
- concise
- professionally structured

Instead of manually copying information into slides, Claude should organize, summarize, and structure presentations automatically.

# Core Presentation Principles

## 1. Slides Should Support the Speaker

Slides are not documents.

Good presentations:
- summarize information
- reinforce key points
- support storytelling
- maintain audience attention

Avoid:
- paragraph-heavy slides
- excessive text
- overly dense layouts
- information overload

Good slides improve:
- clarity
- retention
- engagement

---

## 2. Prioritize Visual Hierarchy

Each slide should clearly communicate:
- the main point
- supporting details
- visual emphasis

Use:
- strong headings
- concise bullets
- spacing
- alignment
- progressive information flow

Good hierarchy improves:
- readability
- presentation pacing
- audience understanding

---

## 3. Keep Content Concise

Presentation slides should:
- communicate quickly
- remain easy to scan
- avoid unnecessary detail

Claude should:
- simplify explanations
- reduce clutter
- remove filler content
- emphasize key takeaways

Avoid:
- large text blocks
- overly technical paragraphs
- unnecessary repetition

---

## 4. Structure the Narrative

Presentations should follow a logical story.

Typical structure:
- introduction
- problem
- context
- solution
- results
- next steps
- conclusion

Strong storytelling improves:
- engagement
- retention
- persuasion

---

## 5. Design for Readability

Slides should remain:
- visually clean
- balanced
- readable from distance
- presentation-friendly

Claude should prioritize:
- spacing
- alignment
- simplicity
- consistent formatting

Avoid:
- cluttered layouts
- excessive animations
- inconsistent structure

# Workflow

## 1. Analyze Source Material

Start by reviewing:
- notes
- reports
- outlines
- documents
- research summaries

Identify:
- key points
- recurring themes
- presentation goals
- audience priorities

Claude should remove:
- unnecessary detail
- duplicated information
- irrelevant sections

---

## 2. Define Presentation Structure

Organize the presentation into sections.

Example:
- Title
- Overview
- Problem
- Solution
- Key Features
- Results
- Roadmap
- Conclusion

Ensure:
- logical flow
- progressive storytelling
- clean transitions

---

## 3. Generate Slide Content

Create:
- concise headings
- supporting bullets
- summaries
- key takeaways

Each slide should focus on:
- one major idea
- minimal clutter
- readable formatting

Avoid:
- overloading slides
- long paragraphs
- excessive bullet nesting

---

## 4. Improve Visual Hierarchy

Refine:
- title structure
- spacing
- emphasis
- content grouping
- readability

Strong hierarchy improves:
- audience comprehension
- pacing
- professionalism

---

## 5. Add Presentation Flow

Ensure slides transition naturally.

Claude should:
- connect ideas logically
- maintain pacing
- avoid abrupt topic jumps
- reinforce narrative structure

The presentation should feel:
- cohesive
- intentional
- easy to follow

---

## 6. Prepare Speaker-Friendly Slides

Slides should support live presentation.

Optimize for:
- quick scanning
- presenter guidance
- visual simplicity
- audience retention

Optional additions:
- speaker notes
- presenter prompts
- discussion points

---

## 7. Final Validation

Before export validate:
- readability
- slide density
- narrative clarity
- visual consistency
- audience alignment

Ensure:
- the deck feels polished
- slides remain concise
- the story flows naturally
