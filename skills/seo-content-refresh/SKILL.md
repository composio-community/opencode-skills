# SEO Content Refresh

Improve existing content by increasing usefulness, not keyword density.

## Core insight

A refresh wins when it better satisfies the searcher's next decision. Rankings follow from intent coverage, freshness, specificity, structure, and trust signals.

## Operating loop

1. Identify target query, page goal, current audience, traffic trend, and conversion goal.
2. Determine search intent: learn, compare, decide, troubleshoot, buy, or implement.
3. Audit the page for missing answers, stale claims, weak intro, thin examples, poor structure, and dead internal links.
4. Add answer-first sections for AI search and featured snippets.
5. Improve trust with firsthand examples, screenshots, data, author expertise, product proof, and caveats.
6. Update title, meta description, headings, internal links, schema hints, and CTA.
7. Preserve URLs unless there is a redirect plan.

## Refresh decision rules

- If the page ranks but does not convert, improve CTA and intent match.
- If the page lost traffic, compare intent drift and freshness.
- If the page is thin, add unique examples before adding more generic text.
- If the page targets multiple intents, split or restructure it.

## Quality bar

- Content becomes more useful to humans first.
- Important answers appear early.
- Internal links and CTA match intent.

## Anti-patterns

- Keyword stuffing.
- Rewriting into generic AI content.
- Changing slugs without redirect strategy.
